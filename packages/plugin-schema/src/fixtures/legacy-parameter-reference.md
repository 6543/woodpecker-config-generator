# Git Push

## Parameter Reference

| setting   | description                            |
| --------- | -------------------------------------- |
| `ssh_key` | private SSH key for the remote         |
| `remote`  | target remote repository               |
| `branch`  | target remote branch, defaults to main |

## Template Reference

| variable     | description |
| ------------ | ----------- |
| `repo.owner` | repo owner  |
