# Git Clone

## Settings

| Settings Name | Default | Description                       |
| ------------- | ------- | --------------------------------- |
| `depth`       | `0`     | set the clone depth, 0 means full |
| `recursive`   | `false` | clone submodules recursively      |
| `partial`     | none    | enable partial clone              |
