# Example corpus

Woodpecker configurations vendored from
<https://codeberg.org/codeberg-ci/examples>, used as test fixtures for AST
round-tripping and path-to-range resolution.

Upstream licence is permissive (ISC-style, see the LICENSE file in that
repository). These files are test data only and are never shipped: the package
publishes `dist` alone.

Refresh with:

```sh
git clone --depth 1 https://codeberg.org/codeberg-ci/examples.git
```
